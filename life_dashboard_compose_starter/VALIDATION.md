- Kotlin parser check по всем `.kt` файлам: синтаксических диагностик `expecting` / `unexpected tokens` не обнаружено.
- `DashboardModels.kt` и `DemoDashboardStore.kt` отдельно скомпилированы с временными заглушками Compose runtime / Color.

Перед использованием в приложении нужно подключить исходники к существующему Android-проекту и выполнить сборку в Android Studio.
