# Этап 3 — Notes и Note Details

## Что реализовано

### Notes list
- Макет сохранён по мотивам предоставленного HTML: заголовок «Заметки», круглая кнопка назад и кнопка поиска, белая строка поиска, горизонтальный ряд фильтров и двухколоночная пастельная мозаика.
- Использован `LazyVerticalStaggeredGrid`, чтобы карточки могли иметь разную высоту и не растягивались под самую высокую карточку в строке.
- Поиск выполняется по заголовку и основному тексту заметки.
- Фильтры строятся по категориям, которые реально присутствуют в списке; у фильтров есть счётчики.
- Закреплённые заметки выводятся выше остальных. Закрепление можно переключить прямо на карточке или в редакторе.
- Есть отдельное пустое состояние и состояние «Ничего не найдено».

### Note Details / editor
- Создание, просмотр и редактирование заметки.
- Поля заголовка и длинного текста.
- Выбор категории: «Приложение», «Блог», «Личное», «Идеи».
- Выбор пастельного цвета карточки.
- Переключатель закрепления.
- Подтверждение удаления существующей заметки.
- Сохранение по кнопке в заголовке. Пустую заметку нельзя сохранить; допускается заголовок без текста или текст без заголовка.

### Навигация и данные
- Открытие заметки из списка: `notes` → `note_details/{noteId}`.
- Создание из списка и центрального Quick Add: `note_details/new`.
- Изменения хранятся в `DemoDashboardStore`, поэтому список обновляется при возврате из редактора.
- Счётчик заметок на плитке Menu теперь берётся из хранилища, а не жёстко задан как 24.

## Проверочные сценарии

1. Открыть Menu → Заметки. Должно отображаться четыре демонстрационные карточки в исходной пастельной палитре.
2. Проверить горизонтальную прокрутку фильтров на узком экране.
3. Ввести слово из заголовка заметки и затем слово только из её текста — в обоих случаях заметка должна находиться.
4. Выбрать категорию; список и счётчики должны соответствовать выбранной категории.
5. Закрепить заметку на карточке. Она должна переместиться выше остальных.
6. Открыть карточку, изменить заголовок и длинный текст, выбрать категорию и цвет, сохранить. При возврате изменения должны быть видны в списке.
7. Создать заметку из центрального Quick Add → Note. После сохранения приложение должно вернуться на предыдущий экран.
8. Создать заметку только с текстом. В списке для неё должно появиться название «Без названия».
9. Попытаться сохранить полностью пустую заметку — сохранение должно быть недоступно.
10. Удалить существующую заметку через подтверждение. Она должна исчезнуть из списка, а счётчик Menu должен уменьшиться.
11. Ввести запрос без совпадений и проверить состояние «Ничего не найдено».
12. Удалить все заметки и проверить пустое состояние с действием создания заметки.

## Ограничения этого этапа

- `DemoDashboardStore` остаётся in-memory хранилищем: заметки не переживают полное завершение процесса приложения.
- Вложения показаны как демонстрационные превью/счётчики из макета. Выбор файлов, открытие вложений и реальное хранение файлов пока не реализованы.
- Автоматическое сохранение черновика при выходе из редактора не реализовано; изменения применяются после нажатия «Сохранить».
- Реальная синхронизация с Room/DataStore отложена до отдельного этапа архитектуры и постоянного хранения.
