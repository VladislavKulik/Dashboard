# Stage 16 — Validation

## Выполненные проверки

- Повторно выполнены проверки Stage 15: Settings/DataStore, ViewModel, уведомления и Kotlin-разделители исходников.
- Kotlin-компиляция `RoomDashboardBackupRepository` с тестовыми заглушками Room, DAO, `org.json` и моделей.
- Kotlin-компиляция Settings UI и темы с Compose API-заглушками.
- Проверка `SettingsRepository.replaceSettings`: одна операция DataStore восстанавливает все три настройки.
- Структурные проверки полного списка таблиц, формата/версии JSON, обязательной валидации, транзакционного удаления/вставки, SAF-launchers, диалога подтверждения, лимита файла и пересоздания напоминаний.
- Проверка синтаксических разделителей всех Kotlin-файлов.

Запуск:

```bash
bash validation/run_stage16_checks.sh
```

## Не проверено

- Полная Android Gradle-сборка, поскольку в переданном наборе нет `gradlew`, `settings.gradle(.kts)`, `build.gradle(.kts)` и Android SDK-конфигурации проекта.
- Реальный round-trip Room + Android `org.json` на устройстве, системный SAF picker, запись в выбранный провайдер документов и восстановление после закрытия приложения.
- Фактическая доставка уведомлений после восстановления расписания на Android-устройстве.

Компиляция с заглушками проверяет согласованность Kotlin-кода с использованными API-сигнатурами, но не заменяет сборку Android-приложения.
