# Life Dashboard — UI design system

Значения основаны на шести HTML-экранах пользователя, а не на первоначальной черновой палитре с оранжевым акцентом.

## Цвета

| Token | HEX | Использование |
|---|---|---|
| Background | `#F7F6FB` | Основной фон экранов |
| Ink | `#151515` | Основной текст, активные элементы, тёмные карточки |
| White | `#FFFFFF` | Карточки, кнопки, плавающая навигация |
| Muted | `#6B6670` | Вторичный текст |
| Muted on dark | `#CFCEDA` | Вторичный текст на чёрной поверхности |
| Yellow | `#FFE680` | Задачи, календарь, центральная кнопка добавления |
| Lavender | `#DCCBFF` | Активность, проекты, аналитические блоки |
| Mint | `#BFEBDD` | Проекты и аналитика |
| Pink | `#FFC8DC` | Задачи и привычки |
| Blue | `#BFE2FF` | Статистика и цели |
| Purple | `#7A55D6` | Акценты графика недели |
| Purple light | `#B79BFF` | Более светлые значения на графике / календаре |

Цвета карточек — смысловые категории, а не набор взаимозаменяемых декораций. Не назначай цвет случайно на каждом экране.

## Навигация

Постоянная нижняя панель содержит четыре позиции: Home, Projects, Add, Menu. Вторичные разделы (Notes, Analytics, Habits, Goals, Settings) открываются из Menu и сохраняют выбранное состояние Menu в нижней панели.

## Правила переноса макетов

1. Не ограничивать экран фиксированной высотой 844 dp.
2. Не обрезать горизонтальный ряд: применять прокрутку или перенос.
3. Нижняя навигация должна оставаться видимой при прокрутке.
4. Не менять палитру и пропорции карточек без согласования.
5. Сначала добиваться визуального совпадения, затем подключать бизнес-логику.
