# Stage 13 — Habits CRUD и настройки напоминаний

## CRUD привычек

`HabitsRepository` теперь разделяет создание, редактирование и удаление:

- `createHabit()` добавляет новую привычку с пустой историей;
- `updateHabit()` изменяет название, цвет и параметры напоминаний;
- `deleteHabit()` удаляет привычку и её историю отметок;
- `toggleCompletion()` по-прежнему переключает отметку за выбранную дату.

Форма создания доступна на экране «Привычки». Редактор открывается с экрана деталей через кнопку с карандашом. Удаление доступно со страницы деталей и требует подтверждения.

При редактировании репозиторий читает актуальную строку из Room и меняет только редактируемые поля. `completionDates` берётся из базы, а не из открытой формы: история не затирается, если пользователь успел отметить привычку, пока редактор был открыт.

## Параметры напоминаний

Для каждой привычки хранятся:

- `reminderEnabled` — включено ли напоминание;
- `reminderTime` — локальное время в формате `HH:mm` (24-часовой формат);
- `reminderDays` — дни недели ISO: 1 = понедельник … 7 = воскресенье;
- `reminderLabel` — краткое текстовое представление для совместимости со старым UI.

В редакторе можно включить/выключить напоминание, указать время и выбрать дни недели. Время проверяется до сохранения. При отключённом напоминании сохранённые время и дни остаются в модели, но не считаются активными.

**Важно:** Stage 13 сохраняет настройки напоминаний, но ещё не планирует системные Android-уведомления. Запрос разрешения `POST_NOTIFICATIONS`, точное расписание, `AlarmManager`/WorkManager, восстановление расписания после перезагрузки и отмена уже запланированных уведомлений относятся к следующему этапу.

## Изменение Room

Версия БД повышена с 3 до 4. Миграция `MIGRATION_3_4` добавляет к `habits` три столбца:

- `reminderEnabled INTEGER NOT NULL DEFAULT 0`;
- `reminderTime TEXT NOT NULL DEFAULT '09:00'`;
- `reminderDays TEXT NOT NULL DEFAULT '1,2,3,4,5,6,7'`.

Настройки напоминаний у существующих привычек после миграции выключены. Идентификаторы, названия, цвета и история выполнений не меняются. `@ColumnInfo(defaultValue = ...)` синхронизирован с SQL defaults.

## Границы этапа

- Нет системных уведомлений и запроса Android-разрешения.
- Нет выбора отдельной даты начала/окончания напоминания.
- Удаление привычки намеренно удаляет связанную историю её отметок; перед удалением показывается подтверждение.
