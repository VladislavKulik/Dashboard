# Stage 9 — HabitsRepository

## Что изменено

- Добавлен контракт `HabitsRepository` с `observeHabits`, `saveHabit` и `toggleCompletion`.
- `RoomDashboardPersistence` реализует контракт и публикует список привычек через Room `Flow`.
- Отметка выполнения переключается по локальному ключу `yyyy-MM-dd` внутри `RoomDatabase.withTransaction`: чтение текущей истории, изменение множества дат и запись выполняются атомарно.
- `DashboardViewModel` наблюдает привычки после первоначального восстановления, создаёт новые привычки и отправляет команды отметки выполнения.
- `LifeDashboardApp` получает список привычек из общего `DashboardUiState`; экраны больше не читают и не изменяют `DemoDashboardStore` напрямую.
- Устаревшие методы изменения привычек удалены из `DemoDashboardStore`.
- Ошибки записи привычек отображаются на экране Habits.
- Снимки Dashboard больше не очищают и не перезаписывают таблицу привычек. Демонстрационные привычки добавляются только при первичном заполнении пустой базы.

## Сохранность истории

Каждая привычка хранит локальные даты завершения в виде отсортированного списка ключей `yyyy-MM-dd`, разделённых запятыми. Повторная отметка той же даты снимает её. Операция выполняется в транзакции, поэтому параллельные изменения не теряют историю.

## Ограничения

- Удаление и редактирование привычек пока не представлены в UI и API.
- Таблица `habits` использует существующую схему Room версии 1, миграция не требуется.
- `DemoDashboardStore` пока остаётся временным read-model фасадом для общего состояния, проектов и аналитики. Привычки больше не используют его как источник записи.
- Проверка полноценной Android Gradle-сборки невозможна без Gradle Wrapper, build-файлов и конфигурации SDK исходного Android-проекта.
